# Afterglow for Windows

Installers for testers of Afterglow, a private film and series watchlist. This repository contains releases only; the source code is private.

## Install

1. Open the [latest release](https://github.com/T0mmyS13/afterglow-releases/releases/latest) and download `Afterglow-Setup-<version>.exe`.
2. Run it. The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC": click **More info** → **Run anyway**.
3. On first launch, enter the setup code you received. It gives you your own profile; nobody else sees your list.

## Updates

Afterglow checks for updates on start and every few hours. A new version downloads in the background and installs when you close the app, or right away if you choose **Restart now**.
